# 🐾 Clyvo Vet

Aplicativo mobile desenvolvido em React Native com Expo para gerenciamento de pets.

---

# 📱 Funcionalidades

✅ Cadastro de pets  
✅ Listagem de pets  
✅ Visualização de detalhes  
✅ Remoção de pets  
✅ Persistência de dados com AsyncStorage  
✅ Score de saúde  
✅ Alertas inteligentes  
✅ Status de saúde do pet  
✅ Navegação entre telas  

---

# 🚀 Tecnologias Utilizadas

- React Native
- Expo
- Expo Router
- AsyncStorage
- JavaScript

---

# ▶️ Como executar o projeto

## 1. Clone o repositório

```bash
git clone https://github.com/Vitor-Augusto-olv/clyvo-ve
```
## 2. Acesse a pasta do projeto

```bash
cd clyvo-ve
```

## 3. Instale as dependências

```bash
npm install
```

## 4. Execute o projeto

```bash
npx expo start
```

## 5. Abra no celular

```bash
Instale o aplicativo Expo GO
Escaneie o QR Code exibido no terminal
```

## Estrutura de pastas
```bash
app/
 ├── index.js
 ├── home.js
 ├── pets.js
 ├── cadastrar.js
 ├── perfil.js
 ├── saude.js
 └── _layout.js
```

## Armazenamento de Dados
Os dados dos pets são armazenados localmente utilizando AsyncStorage.

Mesmo fechando o aplicativo, as informações permanecem salvas no dispositivo.

O objetivo do aplicativo é facilitar o gerenciamento e acompanhamento da saúde dos pets de maneira simples, intuitiva e acessível.
